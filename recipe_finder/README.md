# Recipe Finder

This is a simple command-line application that helps you find recipes based on the ingredients you have at home.

## How to Use

1.  Make sure you have Python installed.
2.  Navigate to the `recipe_finder` directory.
3.  Run the application with the following command:
    ```
    python app.py
    ```
4.  You will be prompted to enter the ingredients you have, separated by commas.
5.  The application will then display any recipes you can make with your ingredients.
